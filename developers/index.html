The first file-conversion SDK with zero server costs. Integrate ShiftFile Tools into your apps.

Quick Start

Include the SDK in your HTML:

<script src="/assets/js/shiftfile.sdk.js"></script>

Use the global ShiftFile object:

ShiftFile.convertImage(file, 'webp', 0.9).then(blob => { /* do something */ });
