Frequently Asked Questions

Does it handle non-English characters?
Yes, casing preserves Unicode characters. snake_case and kebab-case only keep ASCII letters and numbers.
What is Title Case vs Sentence case?
Title Case capitalizes every word. Sentence case capitalizes only the first word.
Is there a character limit?
No hard limit, but extremely long strings may slow down the browser.
