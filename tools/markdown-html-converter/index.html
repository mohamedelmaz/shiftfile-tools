Frequently Asked Questions

Does it support full CommonMark?
No, it supports a subset: headings, bold, italic, code, links, images, lists, blockquotes, and horizontal rules.
Is HTML in Markdown allowed?
HTML input is escaped before parsing, so only generated tags are kept. Raw HTML in Markdown input is not rendered.
Are my texts uploaded?
No. Everything runs locally in your browser.
