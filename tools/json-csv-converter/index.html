Frequently Asked Questions

Does it support nested JSON?
No, only flat arrays of objects are supported. Nested structures should be flattened before conversion.
How are commas and quotes handled?
Fields containing commas or quotes are wrapped in quotes with internal quotes doubled, following RFC 4180.
Is there a size limit?
No hard limit, but very large JSON may freeze the browser tab.
