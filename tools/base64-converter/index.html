Frequently Asked Questions

Is Unicode supported?
Yes, we use TextEncoder and TextDecoder to handle Unicode safely.
Can I decode any Base64 string?
Any valid Base64 string can be decoded. Invalid strings will return an error.
Are files uploaded?
No. File encoding happens locally in your browser.
