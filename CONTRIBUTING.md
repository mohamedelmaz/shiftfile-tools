# Contributing to ShiftFile Tools

Thank you for your interest in contributing! Here is how you can help:

## How to Contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-change`.
3. Make your changes.
4. Test locally by opening `index.html` in a browser.
5. Commit with a clear message: `git commit -m "Add feature X"`.
6. Push to your fork and open a Pull Request.

## Rules

- Use vanilla JavaScript — no frameworks, no build step, no backend.
- Write original content and code. Do not copy from other projects.
- Keep files relative so the site works locally and when deployed to the root.
- Follow the existing CSS variable naming and structure.
- Do not add secrets or sensitive data.
- Run `npm run lint` if available, or verify manually that the page works.

## Questions?

Open an issue or contact us at hello@shiftfile.tools.
